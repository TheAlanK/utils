# Utilities

Things that I've developed for me (and perhaps others) to use in the future:

1- Brazilian phone number anonymization with ddi numbers. ex.: 5511978945612

2- Email anonymization

3- UberWatch: personal Android app that watches the Uber price on screen (via Accessibility Service) and notifies on price drops. APK is built in the cloud by the `UberWatch Build APK` GitHub Actions workflow — no Android Studio needed. See `UberWatch/README.md`.
